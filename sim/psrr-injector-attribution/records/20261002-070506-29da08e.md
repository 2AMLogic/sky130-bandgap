## Variants -- what each body cuts, and what that isolates

| variant | substitution | isolates |
|---|---|---|
| `base` | core + injector, unmodified | reproduces the cited record on this script's own code path |
| `core_only` | the `XSU startup_injector` instance removed from the testbench wrapper | the bare core (report row 4a) -- the CONTROL and the recovery ceiling |
| `ref_open` | `MPC1`/`MPC2` removed; `NG` held at `VSS` by a 0 V source | the diode-connected PMOS reference stack: both its own GDRV load and the `NG` bias it imposes on `MNI` |
| `inj_open` | `MNI` (the injector NMOS, drain on GDRV) removed | `MNI`'s own drain load on GDRV, with the reference stack and its `NG` bias left in place |
| `clamp_open` | `MNC` (the issue-#52 railed-branch clamp, source on GDRV) removed | `MNC`'s own source load on GDRV |

Every device the injector places on GDRV has its own variant. GDRV is the only node the injector can act through at this operating point -- its `VSENSE` pin is a high-impedance gate and its `VDD` pin feeds only the two PMOS bulks (see `sim/psrr-dc-with-injector/experiment.json`'s last note) -- so this set is exhaustive over the mechanism. `MNS`/`QS` have no variant of their own because they do not touch GDRV: they reach it only through `NG`, which is exactly what `ref_open` holds fixed.
