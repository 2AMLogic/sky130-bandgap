## Experiment description and record history

Moved verbatim from the "Experiments that do not go through the corner runner" table in `sim/README.md` (issue #339). The newest entry under `records/` is authoritative for the current verdict; the text below was written when the cited records were current.

**Device-branch attribution, not a spec claim** (issue #306, follow-up to #300): answers *which* device inside `design/startup_injector.sch` dominates the DC-1 kHz PSRR collapse `sim/psrr-dc-with-injector` records, which that bench cannot answer because it attaches the whole injector cell at once. Needs its own script for two reasons the corner runner's one-deck-per-PVT-point model does not cover: (i) the axis is **body variant × corner**, five bodies over the full 45-point matrix (225 ngspice points), where each body differs from the next by exactly one GDRV-touching device branch being cut — `base`, `core_only` (the `XSU` instance removed: the control and the recovery ceiling), `ref_open` (`MPC1`/`MPC2` cut, `NG` held at `VSS`), `inj_open` (`MNI` cut), `clamp_open` (`MNC` cut); and (ii) the circuit under the knife is the **committed netlist snapshot** `sim/psrr-dc-with-injector/netlist-snapshots/20260923-124813-af9ff1e.spice` — the exact body the cited record measured — **not** a fresh xschem netlist of `design/`, so that a later fix to `design/startup_injector.sch` cannot silently re-point this attribution at the fixed design. Measurement expressions, limits, solver options and the `ac dec 10 0.1 1meg` sweep are byte-identical to `sim/psrr-dc-with-injector/experiment.json`'s, so every number is corner-for-corner comparable to report rows 4a/4d. Its checks are **attribution assertions, not spec verdicts** (`base_reproduces_cited_record`, `control_core_only_clears_floor`, `clamp_not_a_contributor`, `ref_stack_is_dominant`, `ref_open_restores_control`). Current record `20261002-070506-29da08e`, `Overall: FAIL` on 4 of 429 assertions — the result is that `MPC1`/`MPC2` is the **dominant** contributor (cutting it recovers 45/45, worst 65.64 dB) but not the only one: `MNC` is exonerated outright (≤0.25 dB everywhere) while `MNI` leaves a measured hot-corner residual (cutting it alone recovers only 43/45, and the two `sf, 125 °C` corners leave 2.03/3.07 dB unrecovered when only the stack is cut). Report row 4e; fix disposition in `spec/decision-records/DR-011-startup-injector-psrr-fix-infeasible-by-resize.md` and issue #315
